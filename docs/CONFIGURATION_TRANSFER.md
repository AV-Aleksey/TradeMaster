# Экспорт и импорт сигналов и настроек

Откройте **Настройки → Экспорт и импорт**. Доступны три состава JSON-файла:

- **Сигналы и настройки**: все пары с кодами, источниками и площадками, все схемы сигналов, выбранная пара, таймфрейм графика, включение звука и громкость.
- **Только сигналы**: все схемы и описания связанных пар.
- **Только настройки**: список пар и настройки графика/звука, без схем сигналов.

Чтобы сохранить отдельный сигнал, нажмите кнопку экспорта на его карточке. Условия И/ИЛИ, параметры индикаторов, таймфреймы, точные десятичные значения и поддерживаемые схемой дополнительные правила сохраняются без преобразования редактором.

После выбора файла импорта показываются количество пар и сигналов, наличие настроек и источники. До нажатия **Импортировать** текущая конфигурация не меняется. Отмена файлового диалога также ничего не меняет.

Режимы:

- **Добавить** сохраняет существующие сигналы, добавляет импортированные как отдельные схемы и применяет настройки, если они есть в файле. Существующая пара используется только при совпадении источника, площадки и кода; недостающие пары добавляются. Повторный импорт создаёт новые экземпляры сигналов.
- **Заменить** для общего файла заменяет все пары, сигналы и переносимые настройки. Для файла только с сигналами заменяется весь список сигналов, а пары и настройки графика/звука сохраняются. Перед подтверждением интерфейс показывает предупреждение. Для файла только с настройками замена сигналов недоступна.

Импортированные сигналы получают новые идентификаторы, сохраняя версии и условия; события журнала продолжают ссылаться на прежние экземпляры. Импортированные сигналы выключены. Общий мониторинг и доставка Telegram после любого импорта выключены, сохранённая очередь уведомлений сигналов приостановлена. Запускайте нужные сигналы и мониторинг вручную после проверки источников.

API-ключи, JWT, токен и привязка Telegram, котировки, история событий и очередь доставки не экспортируются. Сохранённые на этом компьютере секреты и история при импорте остаются. На другом компьютере ключи и Telegram нужно настроить отдельно. Наличие источника в файле не подтверждает доступность котировок по текущему ключу.

Формат имеет маркер `trademaster-configuration`, версию `1` и дату экспорта UTC. Максимальный размер — 5 МБ, до 500 пар и 1000 сигналов. Проверяются версия, параметры, глубина схем, уникальность идентификаторов и ссылки на пары. Неподдерживаемые источники и повреждённые файлы отклоняются до сохранения. Конфигурация и приостановка очереди сигналов сохраняются одной транзакцией SQLite.

Проверки: `npm test`, `npm run build`, `npm run test:configuration`. Последняя команда запускает отдельный Replay-профиль Electron и проверяет реальный путь UI → IPC → файл → предпросмотр → SQLite → перезапуск; системные диалоги в тесте заменяются выбором временного файла, ключи пользователя не используются.
