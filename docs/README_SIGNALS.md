# Сигналы из README

Оба шаблона создаются для выбранной пары, с периодом проверки **5m**, выключенными. Кнопка **«Из README · вверх и вниз»** добавляет отсутствующие шаблоны; повторное нажатие не затирает пользовательское редактирование. Это обычные редактируемые схемы общего движка, а не отдельные детекторы.

Источник — первая часть README «Сигналы: цепочка подтверждений», а не четыре отдельных паттерна из старого черновика. По уточнению пользователя объёмные участки взяты из старого определения: **максимум → последующий минимум → текущая свеча**, а не от границы кросса.

| Блок | Разворот вверх | Разворот вниз |
|---|---|---|
| Триггер | EMA 5 пересекла EMA 10 вверх | EMA 5 пересекла EMA 10 вниз |
| Предшествующее движение, И с кроссом | close[0] < close[−10] ИЛИ EMA5[−5] < EMA5[−10] | Зеркально, со знаком > |
| Стохастик, область −3…+3 от триггера | В окне был %K ≤ 20; в окне был кросс %K/%D вверх | В окне был %K ≥ 80; кросс вниз |
| Стохастик, на свече подтверждения | %K[0] > %K[−1] | %K[0] < %K[−1] |
| MACD, от триггера до +3 | hist[0] > hist[−1] И macd > signal | Зеркально, со знаком < |
| Сброс | Обратный кросс EMA 5/10 | Обратный кросс EMA 5/10 |
| Подтверждённая метка на свече завершения | EMA30[0] > EMA30[−3] И EMA90[0] > EMA90[−3] И отношение объёмов > 1.2 | Фон со знаком < И отношение объёмов < 0.8 |
| Иначе, если условия метки известны и ложны | «Разворот вверх: ранний» | «Разворот вниз: ранний» |

Стохастик — 10/5/5 (SMA-сглаживание). MACD — 6/8/4, WMA для основных средних и сигнальной линии. EMA — по ценам закрытия, SMA-инициализация.

EMA-кросс: предыдущие значения допускают равенство, текущие — строго выше/ниже. Кросс стохастика повторяет точные неравенства README: предыдущее значение строго ниже/выше, текущее допускает равенство. В конструкторе это операция **«Пересечение с касанием»**.

Подтверждения параллельны, требуются оба; факт каждого запоминается. Проверка направления %K относится к свече, на которой принимается стохастическое подтверждение. Последующая перепроверка уже принятого подтверждения выключена, согласно правилу README «отмечаем и ждём второе»; эту политику можно изменить в редакторе. Новый триггер заменяет старую цепочку. Окно включает свечу кросса и следующие три; cooldown = 0.

Для объёмного отношения рассматриваются последние 20 закрытых свечей, включая текущую. Выбирается максимум High, затем минимум Low строго после него. При равных экстремумах выбирается последний. Средний объём пролива — от максимума до минимума включительно; средний отскока — от минимума до текущей включительно. Минимум входит в оба участка. Если минимум текущий, отскок состоит из одной свечи — это соответствует включительной формуле среднего из старого README.

При отсутствии нужного участка/объёма или нулевом среднем пролива отношение неизвестно. Если из-за этого нельзя определить силу, цепочка всё равно создаёт событие с меткой **«Недостаточно данных»**, а не маскирует неизвестность как обычный ранний сигнал. Если фон уже явно не совпал, условие подтверждённой метки ложно независимо от объёма и применяется ранняя метка.

Синтетические тесты подтверждают исполнение схем, а не их торговую результативность. Проверка этих шаблонов на истории и оценка полезности — отдельный этап. На Forex используется объём, переданный выбранным источником; он не приравнивается автоматически к биржевому объёму SUI/USDC.
