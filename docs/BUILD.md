# Сборка TradeMaster

Конфигурация установщиков: `electron-builder.config.cjs`. Внутри приложения находятся собранные main/preload/renderer, worker, нативные зависимости и звук. Ключи, `.env`, `.local`, базы разработки и исходные документы в установщик не входят.

## Подготовка

- Node.js 22.23.1 (версия указана в Volta и `.nvmrc`).
- macOS для macOS-сборки, Windows для Windows-сборки. Сборка и запуск на Windows пока не проверены.
- `npm ci` — устанавливает зависимости, Electron и подготавливает SQLite. Первая установка и упаковка требуют интернета для загрузки Electron и инструментов electron-builder.

## macOS: локальная сборка

```sh
npm run package:mac
npm run package:verify
```

По умолчанию используется архитектура текущего Mac. Для Apple Silicon доступны `npm run package:mac:arm64`, для Intel — `npm run package:mac:x64`. Запуск Intel-сборки на Intel Mac должен проверяться отдельно; сейчас проверена arm64.

Результаты для текущей версии:

- `release/TradeMaster-0.1.1-mac-arm64.dmg` — образ для установки перетаскиванием приложения в Applications.
- `release/TradeMaster-0.1.1-mac-arm64.zip` — архив приложения.
- `release/mac-arm64/TradeMaster.app` — приложение для непосредственной локальной проверки.

```sh
open release/mac-arm64/TradeMaster.app
```

Локальный режим использует **ad-hoc подпись**, без Developer ID и нотариализации. Это не делает приложение доверенным для Gatekeeper на других Mac. Не следует распространять такой файл как готовый подписанный релиз. Используемый Electron требует macOS 13 или новее.

Если macOS блокирует вашу тестовую копию как приложение неизвестного разработчика, после попытки запуска можно разрешить её в «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть», если эта кнопка доступна для показанного предупреждения. Это ручное разрешение для конкретного Mac, не замена подписи релиза. [Инструкция Apple](https://support.apple.com/en-gb/102445).

## macOS: релиз без ручного снятия карантина

Для штатного прохождения Gatekeeper нужны **Developer ID Application** и нотариализация Apple. Автоматического запуска `sudo xattr -cr`, удаления quarantine или отключения Gatekeeper в установщике нет. Подробности: [документация Apple](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution).

1. Подготовить сертификат Developer ID Application с закрытым ключом в локальной связке ключей. Сертификат Developer ID Installer предназначен для другого типа пакетов и не заменяет Application.
2. Сохранить учётные данные нотариализации в Keychain интерактивной командой, не добавляя пароль в репозиторий:

```sh
xcrun notarytool store-credentials TradeMaster-notary
```

3. Указать сертификат и профиль Keychain, затем собрать:

```sh
export CSC_NAME="Developer ID Application: YOUR NAME (TEAMID)"
export APPLE_KEYCHAIN="$HOME/Library/Keychains/login.keychain-db"
export APPLE_KEYCHAIN_PROFILE="TradeMaster-notary"
npm run package:mac:signed
npm run package:verify
```

Также поддерживаются стандартные для electron-builder переменные `CSC_LINK`/`CSC_KEY_PASSWORD` и способы авторизации нотариализации через App Store Connect API или Apple ID. См. [macOS в electron-builder](https://www.electron.build/v26/docs/mac/). Значения сертификатов, паролей и API-ключей не нужно передавать в чат или коммитить.

Режим `--signed` требует настроенных сертификата и нотариализации. Он включает hardened runtime, обязательную подпись и нотариализацию со stapling; отсутствие учётных данных останавливает сборку, без подмены релиза локальной ad-hoc сборкой.

Проверки после подписанной сборки:

```sh
codesign --verify --deep --strict --verbose=2 release/mac-arm64/TradeMaster.app
spctl --assess --type execute --verbose=4 release/mac-arm64/TradeMaster.app
xcrun stapler validate release/mac-arm64/TradeMaster.app
```

До распространения проверить скачанный установщик на другом Mac с обычными настройками Gatekeeper. Первая штатная проверка запуска может показывать подтверждение об открытии загруженного приложения; ввод команд `xattr` для корректного подписанного и нотариализованного релиза не должен требоваться.

## Windows

Выполнить на Windows с Node.js 22.23.1:

```sh
npm ci
npm run package:win
npm run package:verify
```

Результат: `release/TradeMaster-0.1.1-setup-x64.exe`. Установщик NSIS позволяет выбрать папку установки и создаёт ярлыки. Данные пользователя не удаляются при удалении приложения. Подпись Windows-сборки сертификатом издателя пока не настроена; для публичного Windows-релиза она готовится отдельно.

## Проверка упакованного приложения

`npm run package:verify` запускает именно упакованное приложение в отдельном временном профиле, проверяет архив ASAR, наличие worker/preload/звука и распакованного SQLite, загрузку свечей на локальном источнике, воспроизведение звука и сохранение настройки после перезапуска. Это проверка упаковки, она не заменяет регрессию сигналов или проверку реального API.

Путь к другой сборке можно передать явно:

```sh
npm run package:verify -- release/mac-x64/TradeMaster.app
```

`npm run package:dir` собирает приложение без установщика. Автоматической публикации и загрузки файлов на внешние площадки нет.

## Данные установленного приложения

Установленная версия использует системный каталог `app.getPath('userData')`, а разработка — `.local/app-data`. Установщик не содержит ваших настроек; ключи и Telegram нужно настроить в установленной версии. SQLite и зашифрованные ключи не хранятся внутри `.app` или каталога установки. При обновлении сохраняйте appId и имя приложения, чтобы не менять профиль хранения.

Если задан `TRADEMASTER_DATA_DIR`, этот отдельный каталог используется и для данных TradeMaster, и для профиля Electron. Проверка упаковки использует такой временный каталог и не читает рабочие ключи.

Хранение ключей использует асинхронный safeStorage Electron 45. Старые файлы, созданные синхронным API, читаются без повторного ввода ключа. Если Electron сообщает о необходимости обновить шифрование, файл заменяется атомарно; при ошибке сохраняется прежний файл. Действия с ключами выполняются последовательно, чтобы исключить перезапись более новой замены старым асинхронным запросом.
